## Image Guidelines

- **Format**: Use PNG for better quality and transparency support
- **Resolution**:
  - Desktop screenshots: 1200x800 pixels minimum
  - Mobile screenshots: 375x812 pixels (iPhone size)
  - Charts/cards: 600-800 pixels wide
- **Quality**: Use high DPI/retina quality when possible
- **Consistency**: Use the same browser theme and window size
- **Content**: Ensure text is readable and UI elements are clear

## Taking Screenshots

### Preparation

1. Run both frontend (`npm run dev`) and backend (`python main.py`)
2. Use a clean browser profile or incognito mode
3. Set browser window to consistent size (1200px wide recommended)
4. Ensure good lighting/contrast for screen capture

## File Naming Convention

Use descriptive, lowercase names with hyphens:

- `feature-name.png` for specific features
- `page-name.png` for full page views
- `component-name.png` for specific components

## Usage in Documentation

Reference screenshots in Markdown using relative paths:

```markdown
![Description](screenshots/filename.png)
_Caption describing the image_
```
